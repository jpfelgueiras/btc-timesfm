# BTC Forecast Ensemble

Experimental BTC/USD forecasts using TimesFM and baseline models. Forecasts are
not financial advice; historical performance does not guarantee future results.

## Quick start

Requires Python 3.11–3.13 and [uv](https://docs.astral.sh/uv/). The checked
test-only setup and locally generated forecast commands are in the
[Getting started guide](https://jpfelgueiras.github.io/btc-timesfm/getting-started/).
That guide is the tested source for installation, running tests, and optional
model setup.
